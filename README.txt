برنامج حسان المحاسبي - مشروع iPhone جاهز للبناء

هذا المشروع يستخدم نفس index-mobile-menu.html الأساسي بدون تغيير في وظائف البرنامج.

البناء الرسمي لتطبيق iPhone يحتاج macOS + Xcode في مرحلة iOS النهائية. يمكن استخدام Mac سحابي.

على Mac:
1) npm install
2) npx cap add ios
3) npx cap sync ios
4) npx cap open ios
5) من Xcode اختر Signing & Capabilities وحساب Apple Team ثم Run على iPhone.

ملاحظة: هذا المشروع لا يغيّر نسخة Windows أو Android.
